# Les PDF d'horaire à récupérer

Huit masters restent à relever. Le MScIS et le MScCCF sont faits.

Chaque lien ouvre directement le PDF de l'horaire officiel : tu l'enregistres,
et tu déposes tous les fichiers dans `horaires/` sans te soucier des noms.
Je les identifie à partir de leur contenu.

Quand une page annonce « Pas de cours pour cette sélection », il n'y a rien à
enregistrer, passe à la suivante.
